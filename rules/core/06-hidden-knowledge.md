# Hidden Knowledge Template (암묵적 지식 템플릿)

코드베이스 검색만으로는 파악할 수 없는 아키텍처 결정의 "이유(Why)", 비직관적 도메인 로직, 해결되지 않은 기술 부채 등을 명시하여 AI가 치명적인 실수나 무단 수정을 하지 않도록 방어하는 암묵적 지식 템플릿입니다.

---

## 🧠 암묵적 지식 및 도메인 컨텍스트 (Hidden Knowledge)

*(대상 프로젝트 구성 시 아래 예시를 참고하여 실제 도메인 특화 지침을 작성하십시오.)*

- **아키텍처 결정의 이유**: [예: Redux 대신 Zustand 사용. 이유: 보일러플레이트 최소화 및 상태 동기화 직관화]
- **엄격한 접근 제약**: [예: `src/core/auth/` 폴더 내의 코드는 보안 감사팀의 리뷰 없이 절대 구조를 변경하지 말 것]
- **비직관적 비즈니스 로직**: [예: 포인트 환산 시 국가별 세금 정책 공식 적용 필수]
- **해결되지 않은 기술 부채**: [예: `legacy_api.js` 파일은 향후 Deprecate 될 예정이므로 수정 금지]
